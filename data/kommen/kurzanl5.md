# Kurzanleitung

*Robert Rettig, aus der Original-Dokumentation von HORCOM (Ordner KOMMEN7P), unverändert bis auf die Formatierung.*

KURZE ANLEITUNG zum schnellen Einstieg in HORCOM :

____________________________________________________________________ Hardware-Voraussetzungen :

INTEL-Prozessor oder kompatibel.Ideal ist ein PENTIUM....

Freier Arbeitsspeicher 20 MBYTE oder größer.

Software-Voraussetzungen :

WINDOWS 9X,NT,XP,VISTA Optimale Auflösung ist 1024*768 mit 256 oder mehr Farben.

Die Bedienung der grundlegenden Bedienelemente von WINDOWS.. -FENSTERN wie "IKONISIEREN = VERKLEINERN",VERGRÖSSERN,ZOOMEN wird als bekannt vorausgesetzt.

Installation :

Haben Sie den HORCOM-Ordner auf einem USB-Stick so können Sie das Programm direkt auf diesem betreiben.Es wird allerdings meist langsamer in der Ausführung sein als wenn es auf der Festplatte installiert ist.

Optimal läuft HORCOM nur nach Installation auf die Festplatte Ihres PC.

Diese läuft wie folgt ab:

WINDOWS ... muß bereits installiert sein.

Legen Sie die HORCOM-CD in das Laufwerk Ihres Computers und öffnen Sie im WINDOWS - ARBEITSPLATZ dieses Laufwerk,womit Sie die Liste der darauf befindlichen Dateien sehen können.

Eine dieser Dateien heißt "INSTALCD.EXE".

Führen Sie nun einen Doppelklick auf dieser Zeile INSTALCD.EXE aus,womit dieses Programm gestartet wird,das dann automatisch die Installation in einen Ordner HORCOM besorgt.

In WINDOWS 9X...,NT,XP,VISTA können Sie die Installation über EINSTELLUNGEN > SYSTEM STEUERUNG > SOFTWARE besorgen,wobei auch das INSTALCD.EXE gestartet wird. Eine Verknüpfung mit dem Desktop ist empfehlenswert.Dann können Sie HORCOM mit Doppelklick auf das HORCOM-Icon vom Desktop starten.

Falls Sie nicht sehr versiert mit dem PC und mit HORCOM sind,vermeiden Sie es,ohne Not mit dem Explorer oder Dateimanager im oder mit dem HORCOM-Verzeichnis zu hantieren.Das kann ins Chaos führen ! Die Dateien von HORCOM sollten nur durch das HORCOM...EXE verwaltet und manipuliert werden !

Durch Doppelklick auf das HORCOM..-ICON starten Sie dann das HORCOM-Programm und gelangen in das HAUPT-MENÜ von HORCOM....

Bedienung von HORCOM in WINDOWS :

Die erste Zeile im Hauptmenü ist lediglich eine Titel-Zeile,die auch das Datum der Version enthält.

Die eigentlich wichtige MENÜ-ZEILE zeigt die Oberbegriffe :

ÜBER HORCOM EIN-AUSG. EPHEMERIDE HOROSKOPE AUSWERTUNG DIVERSES

Wenn Sie einen der Oberbegriffe anklicken entrollt sich eine Liste von Programm-Titeln,die Sie erst einmal alle anschauen sollten damit Sie zu ahnen beginnen was es in HORCOM alles gibt.Lehrreich ist besonders auch, die Menüpunkte VORGABEN...ÄNDERN einmal durchzugehen,um zu sehen was alles beeinflußbar ist.Bei den Vorgaben für HOROSKOPE sollten Sie insbesondere die Farben für den Horoskopring und die Aspekt-Linien nach Ihrem Gusto festlegen oder zunächst die HORCOM-Standardeinstellungen lassen( für den Anfang empfehlenswert ).

Achtung ! Wenn Sie drucken wollen,bitte keine zu hellen Farben wählen, da die Drucker diese eventuell als weiß interpretieren !

Die erste Spalte "ÜBER HORCOM" enthält nur den einführenden Kommentar. Außerdem zeigt sie die Belegung der Funktions-Tasten innerhalb HORCOM. Es werden F1,F2,F3,F5,F6,F8 und F9 für verschiedene Zwecke benutzt.

Erste Versuche :

Drücken Sie aus dem Hauptmenü heraus die RECHTE Maustaste oder F1 und lesen Sie den daraufhin erscheinenden Text.Er enthält das Grundsätzliche zur Art der Bedienung für Neulinge.

Klicken Sie Im Hauptmenü in der Menüzeile EIN-AUSG. an.Es entrollen sich die Menüpunkte,die für die Ein- bzw. Ausgabe und die Aktivierung der einge gebenen Datensätze gebraucht werden.

Klicken Sie gleich die erste Zeile "DATEN-DATEI EIN-AUSGABE" an. Nun erscheint die WINDOWS - FILESELECT-BOX in der Sie zunächst nur die Dateien MUSTER.DAT und MERIDIAN.DAT sehen.

Die Daten-Datei MERIDIAN.DAT beruht auf Beispielen aus früheren Ausgaben des MERIDIAN mit der entsprechenden Datei MERIDIAN.AAF im Ordner ..\AAFDATEN.

Holen Sie einen Datensatz aus MERIDIAN.DAT so erscheint in dem HORCOM-Anzeige-und Eingabe-Fenster ein Knopf namens "AAF-FORMAT" links unten. Damit können Sie den entsprechenden AAF-Datensatz einsehen und evtl. editieren.

Dies gilt auch für jede gültige AAF-Datei,die im Ordner ...\AAFDATEN vorgefunden wird.

Nun kommt eine Abfrage,wie Sie die Daten sortiert haben wollen.Drücken Sie hier zunächst einfach die RETURN-Taste,die jeweils die dick umrandete Wahl. ( hier ALPHABETISCH ) vornimmt.

Bei den HORCOM-eigenen Dialogen kann statt der RETURN-Taste meist auch die LEERTASTE verwendet werden ( bei WINDOWS-Dialogen nicht immer ! ) Im allgemeinen ist es daher zweckmäßig,den linken Daumen zur Betätigung der Leertaste zu verwenden und die rechte Hand für die Maus !-

Nun entfaltet sich eine Liste z.B.mit den Namen historischer Persönlichkeiten. Klicken sie nun einen oder bis zu 5 Namen einmal an und klicken dann in das Kästchen "WAHLENDE" .-Hier keinen Doppelklick ausführen,da es sich möglicherweise um eine Mehrfach-Auswahl handelt-.Daraufhin erscheint die ANZEIGE-BOX mit den entsprechenden Daten.Bei Doppelklick verlassen Sie die Liste ! Aktiv bzw. gültig ist jeweils der als letzter gewählte Datensatz.Er ist durch ein vorangestelltes Häkchen markiert.

Durch Anklicken eines anderen der ausgewählten Datensätze wird dieser als aktiv selektiert.

Nun können Sie mit dem aktiven Datensatz irgend etwas tun,z.B. ein Horoskop machen.

Sie sind nun wieder im Hauptmenü und klicken in der Menü-Leiste den Oberbegriff "HOROSKOPE" an und wenn sich die Liste der Programme entrollt hat, die Zeile "HOROSKOP-GRAPHIK" .Nun wird ein Horoskop gezeichnet,das Sie beliebig lange anschauen können.

Haben Sie einen Ergebnis-Bildschirm vor sich und wollen den zuständigen Erläuterungstext lesen,drücken Sie einfach die Funktionstaste F1 in der obersten Zeile Ihrer Tastatur.

Das Textfenster kann nach Begriffen durchsucht werden.

Die Kommentare 1,2,3,9 und der für "STATISTIK" sind recht umfangreich.Im Menü beziehen sich die Kommentare immer auf die jeweils darüberstehenden Themen.

Die Belegung der Funktionstasten ist durch Anklicken von "ÜBER HORCOM" ersichtlich.

Sie sollten sämtliche Erläuterungen wenigstens einmal querlesen um in etwa zu wissen was es alles zu beachten gibt.

Sehr nützlich ist es auch sämtliche Menüpunkte namens "VORGABEN....ÄNDERN" Punkt für Punkt einmal durchzugehen und so kennenzulernen welche Parameter und wie einstellbar sind.Während der ersten Stunden mit HORCOM auch immer mal die Funktionstaste F1 aus den Ergebnis-Bildschirmen betätigen,damit Sie Routine mit den Einstellmöglichkeiten bekommen.

Lesen Sie auch bitte in der ersten Zeit genau die Texte in den DIALOGEN. Sie haben ebenfalls oft den Charakter von Erläuterungen.

Das Ausdrucken von Erläuterungen geht am einfachsten durch Anklicken des entsprechenden "BUTTONS" mit der Aufschrift "DRUCKEN",allerdings mit einem festen Font.

Auch mit WINDOWS-WORDPAD können Sie natürlich diese Texte ausdrucken,wobei Sie dann den Ausdruck selbst gestalten können.

Noch einfacher geht es wie folgt:

Mit dem Datei-Manager \WINDOWS\HORCOM\KOMMEN5P\KOMM..TXT öffnen und auf den interessierenden Text einen Doppelklick ausführen,womit Sie den Text im WINDOWS-Editor ( = NOTEPAD.EXE bzw. WORDPAD.EXE) vorfinden und alle wichtigen Textverarbeitungs-Möglichkeiten zur Verfügung haben.

Wollen Sie etwas neues mit HORCOM machen,müssen Sie ins Menü zurückgehen. Das kann auf drei Arten geschehen:

```text
  - in das Schließfeld links oben Doppelklicken ( = WINDOWS-like ) oder
  - 2 mal die LEER-Taste drücken.
Die letztere  Möglichkeit ist sicher nicht WINDOWS-like.Ich habe sie
beibehalten damit die Anwender des ATARI-HORCOM ihre Gewohnheit beibehalten
können.
```

Programme die ein * vor dem Namen haben sind unabhängig vom gültigen Datensatz zu benutzen.Es sind meist astronomische Hilfs-Routinen.

Man kann aus allen TABELLEN-Ausgaben heraus,durch Drücken der FUNKTIONS-TASTE F2 das jeweilige Horoskop zwischendurch ansehen und mit 'Esc' wieder zurückgehen.

Eine Sonderstellung nimmt "STATISTIK" ein,ein umfangreiches Modul,das zur statistischen Untersuchung grösserer Dateien dient.

Programme die ein | vor dem Namen haben sind für "langsame" Prozessoren z.B. einem 386er etwas zeitraubend.Hier wird daher,oder falls die Rechenzeit 15 Sekunden überschreitet,der jeweils letzte Bildschirm auf der Harddisk gespeichert,solange die HORCOM-Sitzung dauert und erst beim Verlassen von HORCOM wieder gelöscht.

Wenn Sie ein solches Programm ,nachdem gespeichert wurde,wieder anwählen, können Sie wahlweise das gespeicherte Bild nochmals betrachten oder ein neues machen.

Sind Sie wieder im Menü und fällt Ihnen nochmals etwas zum letzten Ergebnis ein,was Sie sehen wollen,so können Sie unter EIN-AUSG. bei "LETZTES BILD ZEIGEN" anklicken und sich das jeweils letzte Ergebnis in jedem Fall wieder anschauen,solange es nicht durch ein neueres Ergebnis überschrieben ist. ( CLIPBOARD = ZWISCHENABLAGE ).

Dort können Sie übrigens auch das Bild in einer Datei abspeichern,die sich dann im Ordner ..\HORCOM\BILDER befindet.Falls Sie davon Gebrauch machen achten Sie darauf nicht mehr benötigte Bilder wieder zu löschen,da diese viel Speicher benötigen.

Nach diesen notwendigen Zwischenbemerkungen können Sie nun etwas neues machen,z.B. ein SOLAR ansehen.

Dazu gehen Sie in die Rubrik "AUSWERTUNG" und dann in die Zeile "SOLAR-SEPTAR-LUNAR-PLANETARE-PERSONARE" und drücken RETURN womit "SOLAR-HOROSKOP" gewählt ist.

Nach Eingabe von Ort und Zeit über entsprechende Abfragen erscheint nach etwas Rechenzeit ( es wird sehr genau mit Iteration gerechnet ) direkt das SOLAR.

Nun sind Sie nicht mehr in der "RADIX-EBENE" sondern in der "SOLAR-EBENE" von der aus nicht mehr alle Programme sinnvoll und daher teilweise inaktiv geschaltet sind.Das Häkchen in der Rubrik "EIN-AUSG." im Menü steht nun auch nicht mehr unter "RADIX-DATEN" sondern unter "SOLAR.....-DATEN" . Damit Sie wieder alle Programme zur Verfügung haben,gehen Sie wieder in die RADIX-EBENE indem Sie unter RADIX-DATEN den Sie interessierenden Datensatz anklicken.Der hat dann wieder das Häkchen vorangestellt. Schauen Sie sich nun in aller Ruhe die Programm-Titel unter EPHEMERIDE HOROSKOPE,AUSWERTUNG und DIVERSES genau an,damit Sie sehen was es an Oberbegriffen gibt.

Nach Anklicken diese Oberbegriffe werden oft Gruppen von Unterprogrammen eröffnet,die wiederum zum Teil in unterschiedlichen Darstellungsweisen,z.B. als Tabelle oder Horoskop oder als Linear-Graphik mit unterschiedlichen Parametern ablaufen können.

Die Parameter-Einstellungen ( Vorgaben ) sind meist in der ersten Zeile zugänglich ( außer in der Spalte EIN-AUSGAB ).Wenn Sie hier genau Bescheid wissen wollen,bleibt Ihnen die Lektüre der Erläuterungen nicht erspart. Für die ersten Versuche können Sie hier die voreingestellten Einstellungen ( = dick umrandet ) belassen d.h. RETURN drücken.

Nun können Sie vielleicht einen neuen Datensatz,z.B. Ihre Geburtsdaten von Hand eingeben,indem sie unter EIN-AUSG. die 2. Zeile NEU-EINGABE ... anklicken.

Nun erscheint die EINGABE-BOX.

Ab HORCOM6P gibt es zwei Eingabemöglichkeiten.Einmal die "herkömmliche" Eingabebox von HORCOM oder,wahlweise,die umfangreichere für das AAF-Dateiformat.Darüber steht alles in der Datei AAF_KOMM.TXT ,der auch erscheint,wenn man in der AAF-Eingabebox die Taste F1 drückt.

Das hier folgende bezieht sich auf die HORCOM-Eingabebox.

Wenn nichts Anderes gefragt ist,immer GROß-oder KLEIN-BUCHSTABEN,bei EIGEN-NAMEN (auch Orts-Namen) eingeben.Ziffern OHNE PUNKT oder KOMMA ! innnerhalb der vorgegebenen Eingabefelder.

Abgeschickt wird ein Datensatz durch Anklicken des OK - Feldes rechts unten.Solange dies nicht geschehen ist,können die RADIX-Datensätze wie folgt editiert werden : Zwischen den einzelnen Editfeldern kann mit der TABULATOR-Taste,teilweise auch den senkrechten Pfeiltasten hin und hergesprungen werden.Innerhalb der Felder kann mit den wagerechten Pfeiltasten und mit BACKSPACE oder DEL ( ENTF ) editiert werden. Das Weiterschalten von Datenfeld zu Datenfeld kann immer mit der TABULATOR-Taste geschehen,in Gegenrichtung mit SHIFT+TAB oder den Pfeiltasten.

Das Weiterspringen von einem Feld zum nächsten geschieht bei Neueingabe entweder automatisch ,wenn das Feld gefüllt ist oder wahlweise mit TABSTOP je nachdem wie bei VORGABEN EIN-AUSGABE ÄNDERN verfügt wurde !

ACHTUNG ! Mit einem DOPPELKLICK in eines der Editierfelder können Sie jederzeit direkt beim Editieren zwischen der TABSTOP- und der automatischen Version hin- und herschalten.

Damit,hoffe ich,wird jeder zu seiner Gewohnheit finden.

Beim ÄNDERN eines BEREITS BESTEHENDEN DATENSATZES mit dem Cursor zuerst bis in das erste DATUMS-Feld gehen und die Abfrage "ORT SPEICHERN ?" mit NEIN beantworten,dann in das erste Feld ( NAME.. )zurückgehen und mit dem Überschreiben beginnen.

Wollen Sie bereits gefüllte Felder überschreiben,immer vorher mit "ENTF" oder RÜCKTASTE diese Felder vollständig löschen,es sei denn das betreffende Feld ist farblich unterlegt,dann wird automatisch gelöscht. Falls Sie bei der ORTS-Eingabe die entsprechende AUSWAHLBOX sehen wollen ist es bei bereits ausgefüllten Feldern,die man abändern bzw. überschreiben möchte,evtl. notwendig im ersten Feld ( NAME,VORNAME ) einen DOPPELKLICK auszuführen.Ebenso,wenn die Maus nur im letzten ausgefüllten Feld stehen bleibt !!

Beim Ort können Sie einen VORZUGS-ORT festlegen,meist wohl Ihren Wohnort.

Orte,die Sie eventuell später wieder brauchen,können Sie in ORTS-DATEIEN eingeben und bei Bedarf wieder holen.

ORTS-Dateien für die meisten europäischen Länder befinden sich auf der System-Disc.

Alle ORTS-Dateien befinden sich in dem Ordner "\HORCOM\SPEZ_ORT. Wird bei Länge u.Breite statt "E" bzw "N" einfach weitergegangen,so wird dies trotzdem als "E" u. "N" interpretiert.Nur "W" bzw. "S" muß man wirklich eingeben ( vorher "E" bzw. "N" löschen ).Großenteils kann man daher mit der rechten Hand im Ziffernblock eingeben.

Bei Daten v.Chr. geben Sie in dem dafür vorgesehenen Feld,das Sie sonst einfach übergehen,entweder "V" oder "-" (minus) ein und bei jjjj die NORMALE,von den Historikern verwendete Jahreszahl.Bei den bei Ergebnissen dann evtl. vorkommenden NEGATIVEN Jahreszahlen handelt es sich allerdings um die ARITHMETISCHE Zählweise : Z.B. entspricht "Jahr 63 v.Chr" dem Jahr -62 !! das Jahr Null also dem Jahr 1 vor Chr !! Siehe auch Erl.3 bei "KALENDER". Ansonsten sind bei Daten v.Chr. hinter dem Datum die Buchstaben VC gesetzt. Die UHRZEIT ist als ZONENZEIT einzugeben ! Bei ( fast ) allen AUSGABEN wird allerdings GREENWICH-Zeit GZ = GMT = UT angezeigt,da nur diese auch gespeichert wird.

Die UT wird bei vorliegender Zonenzeit wie folgt ermittelt :

```text
                 UT = GMT = ZONEN-ZEIT + ZZD
                 ZZD = ZONENZEIT-DIFFERENZ
```

Bei der NEU-Eingabe von Daten erscheint ein Dialog zum Einstellen der Zonenzeit,falls in der Eingabebox die betr. CHECKBOX angeklickt wurde. Sie zeigt links oben ein Editierfeld und zwei Tabellen in welchen hinter dem ORTS-Namen die ZZD-Werte zu ersehen sind.Wollen Sie eine der entfernteren Zonenzeiten wählen,suchen Sie in der Tabelle nach einer Stadt in dem gesuchten Landstrich und klicken diesen an.In dem Editierfeld erscheint dann dieser Wert und Sie können ihn mit "OK" übernehmen. Für MEZ ( = mitteleuropäische Zeit) ist die ZZD = -1 h .Wollen Sie diese wählen,brauchen Sie die Tabellen nicht sondern klicken einfach auf "OK".

Gilt SOMMERZEIT,so klicken Sie in die betreffende CHECKBOX ( In das kleine Quadrat klicken ! in dem dann ein Kreuz erscheint)..

Für geographische Längen östlich Greenwich ist die ZZD i.a. negativ westlich davon positiv.

Gebräuchliche Abkürzungen für die näherliegenden Zonenzeiten sind:

```text
       MEZ  = MITTEL-europäische Zeit                 ZZD = -1
```

```text
       WEZ  = WEST - europäische Zeit                 ZZD = 0
            = UT = GMT
```

```text
       OEZ  = OST -  europäische Zeit                 ZZD = -2
```

```text
       DSZ  = Deutsche SOMMER-Zeit                    ZZD = -2
```

```text
       DDSZ = Doppelte Deutsche SOMMER-Zeit           ZZD = -3
```

Wollen Sie ORTS-Zeit eingeben,was bei HISTORISCHEN Horoskopen nötig ist markieren Sie die betreffende CHECKBOX und geben in den Zeit-Feldern die angegebene Ortszeit ein.

Bitte nicht ORTSZEIT mit ZONENZEIT verwechseln.In HORCOM wird Ortszeit immer im ursprünglichen Sinn gebraucht.

Eine weitere CHECKBOX unter ORTSZEIT dient dazu zu vermerken,wenn nach dem 15.10.1582 noch der JULIANISCHE Kalender benutzt wurde.Wenn ja,wird unter BEMERKG. die Zeichenfolge "(JULIAN.)" gespeichert,die dann beim Holen aus der Daten-Datei wieder abgefragt und angezeigt wird,aber nur soweit diese Datensätze mit der vorliegenden Version von HORCOM erstellt wurden,was bei der MUSTER-Datei noch nicht der Fall war.In der Daten-Datei wird nämlich immer nur die UT gespeichert.

Stehen Ihnen Dateien im AAF-Format ( Astrologisches Austauch-Format ,das Herr MARTIN GARMS dankenswerterweise etabliert hat ) zur Verfügung,so können Sie solche Dateien mit dem entsprechenden Menüpunkt in der letzten Spalte des Hauptmenüs in HORCOM-Dateien umwandeln oder umgekehrt. Ab Version HORCOM6P können,und sollten Sie dann auch,selbst im AAF-Format editieren.

DRUCKEN von ERGEBNIS-BILDSCHIRMEN

Hinsichtlich DRUCKEN ist grundsätzlich folgendes zu beachten:

* HORCOM ist ein sehr stark Bildschirm-orientiertes Programm.Daher gibt

```text
  es sämtliche Ausdrucke nur entweder als "HARDCOPYS", d.h. der Bildschirm
  wird Punkt für Punkt als BITMAP-GRAPHIK kopiert oder bei einigen wichti-
  gen Ausgaben ( Horoskope,LINEAR-GRAPHIK ) auch als DRUCKER-GRAPHIK wobei
  die höhere  Auflösung des Druckers genutzt wird.
```

* Allgemein ist die Drucker-Unterstützung von WINDOWS wirklich vorbildlich

```text
  zu nennen,soweit man dies angesichts des Fehlens einer verbindlichen
  Normung erwarten kann.
  Aber dem "User" bleibt es trotzdem nicht erspart Experimente zu machen
  um genau das zu erhalten was er sich vorstellt.Man kann mühelos dabei
  viele Quadratmeter Papier und viel Tinte/Farbband verbrauchen.Auch der
  Zeitbedarf für den Ausdruck ist sehr von den Einstellungen abhängig !
  Die Ursache dafür ist die nicht vorhandene Normung und die unterschied-
  liche Qualität der Druckertreiber.Zum Teil wohl auch meine eigene
  Unerfahrenheit mit dem uferlosen Thema.
  Die besten Ergebnisse werden Sie wahrscheinlich erhalten wenn Ihr
  Drucker eine Option für "EPSON-Kompatibel" aufweist.Stellen Sie zunächst
  diese Option ein,da die Firma EPSON fast schon so etwas wie einen
  allgemeinenen Standard für Drucker etabliert hat.
  Allgemeine Regeln anzugeben scheint kaum möglich.Bisher habe ich mit
  3 verschiedenen Druckern experimentiert,was mich zu obigen Bemerkungen
  veranlaßte.
```

* Ihr Drucker muß mit dem richtigen "TREIBER" installiert und angemeldet

```text
  sein.WINDOWS bietet hunderte von Treibern.Sie werden mit Sicherheit
  einen geeigneten finden.
  Zum Einrichten : SYSTEM-STEUERUNG >> DRUCKER >> EINRICHTEN >> OPTIONEN
  durchgehen und die CHECKBOX  "Druckmanager verwenden" aktivieren.
```

* Falls Sie in der Regel 2 Bildschirme auf eine Druckerseite ausdrucken

```text
  wollen,ist es evtl. zweckmäßig daß Sie bei DRUCKER "EINRICHTEN" unter
  SEITEN- LÄNGE eine "BENUTZERDEFINIERTE" Seitenlänge vorgeben,die der
  halben Seitenlänge des benutzten Papierformats exakt entspricht.
  Falls Die exakte Seitenlänge des verwendeten Drucker-Papieres nicht
  in der vorgegebenen Liste vorhanden ist, ( bei meinem Matrix-Drucker
  z.B. nicht ) sollten Sie auf jeden Fall von dieser Möglichkeit Gebrauch
  machen.Ansonsten würde der Drucker immer eine leere Halbseite mit
  ausgeben,oder beim Ausdrucken mehrerer Kopien aus dem Tritt kommen.
  Insbesondere bei Matrixdruckern mit Traktor-Papierzufuhr ist dies sehr
  zweckmäßig.
  Bei manchen Druckern muß man allerdings dazu noch einen DIP-Schalter
  einstellen.
  Überhaupt wird man um die Lektüre des Druckerhandbuches kaum
  herumkommen.Bei meinem Tintenstrahl-Drucker ist es mir bisher nicht
  gelungen ihn zu veranlassen,nach einer Halbseite stehen zu bleiben und
  die nächste Halbseite abzuwarten,wohl aber bei Matrixdruckern.
```

* Es ist unter WINDOWS recht einfach,beliebige Dokumente,also auch die Aus-

```text
   gaben von HORCOM als HARDCOPY auf Matrix-,Laser- oder Tintenstrahl-Druk-
   kern auszugeben.
   Man kann dazu das WINDOWS- Programm WORD oder ein vergleichbares Textver-
   arbeitungsprogramm aktivieren und unter BEARBEITEN auf EINFÜGEN klicken,
   womit der Inhalt des jeweils VORHER AKTIVEN Fensters in das WORD- Fenster
   kopiert wird.Man kann es dann entweder direkt oder nach Hinzufügen eines
   Textes oder zweiten Ausgabe-Bildschirmes mit "DRUCKEN" zu Papier bringen.
```

```text
   Praktisch geht dies am einfachsten in folgenden Schritten:
```

```text
   1. Ausgabe-Bildschirm mit HORCOM erzeugen.
   2. WINDOWS WORD oder ein anderes Textverarbeitungsprogramm öffnen
   3. Unter BEARBEITEN im MENÜ "EINFÜGEN" anklicken.
      Sie sehen nun die Ausgabe auch im WORD-Bildschirm.
      Nun können Sie auf der unteren Blatthälfte evtl. Bemerkungen dazu
      schreiben oder auch noch einen zweiten Ergebnisbildschirm hinzufügen.
      Dazu müssen Sie das "Ikonisieren" und wieder Vergrössern der Fenster
      beherrschen: WORD nicht verlassen,sondern ikonisieren und den zweiten
      Ausgabebildschirm mit HORCOM erstellen.
      Darauf wieder WORD ( das bereits den ersten Bildschirm enthält )
      vergrössern ( rechtes nach oben weisendes Dreieck anklicken !) und
      die letzte HORCOM-Ausgabe mit "BEARBEITEN >> EINFÜGEN" ebenfalls in
      das WORD-FENSTER übernehmen.
   4. Nun im WORD-MENÜ unter DATEI "DRUCKEN" anklicken.Daraufhin erscheint
      Der PRINTER-DIALOG den Sie,wenn einmal alles über "EINRICHTEN"  und
      "OPTIONEN" richtig eingestellt ist,nur mit OK zu beantworten brauchen.
   5. Danach verlassen Sie WORD wieder mit dem Schließfeld.
```

```text
   Eventuell kann auch statt WORD ein Programm wie NETSCAPE-COMPOSER oder
   FRONTPAGE-EXPRESS verwendet werden.
```

Drucker-Steuerung durch HORCOM :

Die Steuerung von Ausdrucken der Ergebnisse kann auch aus HORCOM erfolgen wobei eine gewisse Vielfalt der Möglichkeiten etwas Übung erfordert. Um diese Möglichkeiten alle zu aktivieren muß die "DRUCKER-OPTION" von HORCOM auf "EIN" geschaltet werden.Dies geschieht entweder mit dem entsprechenden Menü-Punkt in der 2. Spalte des Hauptmenüs unten oder durch die Tastenkombination "ALT und D" oder F8 aus den Ausgabe-Bildschirmen heraus.

Unter "VORGABEN EIN-AUSGABE ÄNDERN" in der zweiten Spalte des Hauptmenüs kann vorgewählt werden ob diese Option bei Programmstart immer eingeschaltet werden soll oder nicht.

Ferner kann hier das Normal-Format einer "HARDCOPY" festgelegt werden

```text
nämlich entweder Halbseite oder Ganzseite   (DIN A5 bzw. DIN A4 ) .
```

Eine HARDCOPY ist eine Abbildung des Bildschirme "Punkt für Punkt" und evtl. "Farbe für Farbe".

Ist die DRUCKER-OPTION auf "EIN" ( rechts unten im Menü zu ersehen ) ,so erscheinen Dialoge,welche gestatten die Art der Drucker-Ausgabe zu wählen, bzw. diese zu veranlassen.In diesem Fall erscheint beim Verlassen jedes Ergebnis-Bildschirms rechts unten ein kleiner Dialog mit der Überschrift "HARDCOPY ?".

Wollen Sie nun dieses Ergebnis als HARDCOPY einzeln zu Papier bringen müssen Sie mit "JA" antworten.

Es erscheint dann der Drucker-Dialog von WINDOWS mit dem Sie Ihren Drucker für die Ausgabe einstellen können.Falls Sie mit unterschiedlichen Formaten ausdrucken wollen,dürfen Sie nicht versäumen,mit der Option "EINRICHTEN" das Papierformat richtig einzustellen,das Ihnen von HORCOM durch entsprechende Texte nahegelegt wird.

Daher bitte diese Überschriften beachten und entsprechend einstellen.

```text

  DINA 4 - Seite im HOCHFORMAT auszudrucken.
  Dies geschieht wie folgt,wobei die Funktionstaste F9 zur STEUERUNG
  dient:
```

```text

     CURSOR verwandelt sich,solange dieser Modus aktiv ist in ein Kreuz.
     ACHTUNG! Nur VOLL-BILDER ( keine verkleinerten ) speichern !
  2. Nachdem 2 Ausgaben gespeichert sind,aus dem Haupt-Menü heraus wieder
     F9 drücken,worauf der Doppel-AUSDRUCK veranlaßt werden kann.
```

  Die ist übrigens unabhängig davon welche Größe Sie für EINZEL-
  HARDCOPYS  unter "VORGABEN EIN-AUSGABE ÄNDERN" vorgewählt haben.
