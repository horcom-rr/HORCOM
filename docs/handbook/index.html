The handbook of the C++ rewrite of HORCOM by Robert Rettig

What this handbook is

HORCOM is the astrology program Robert Rettig wrote and refined from the 1970s until 2010, first for the Atari, then in GFA BASIC for Windows. He computed his own ephemerides when none existed, credited every source down to the library shelf mark, and wished for the program to live on in C++. This handbook grows alongside that rewrite. Every page describes one module of the new program, explains the original mechanics it preserves, and lets Robert speak in his own words wherever his comments still tell the story best.

Conventions of the port

Robert's comments travel with the code

Wherever one of his comments still applies to the converted routine it is carried over verbatim, in his German wording, marked with the prefix //RR. One comment per routine names the original HORCOM procedure it was ported from. Code comments stay self contained, they never point at files outside the repository.

Same numbers first

Every ported routine first reproduces the original's output and lands together with its tests, transcription pins plus independent values from the literature Robert himself used, above all Jean Meeus. Only under green tests may a routine be restructured. Where the original and the rewrite disagree, the original is presumed right.

The two integer worlds of GFA BASIC

GFA BASIC has INT, which rounds down, and FIX, which truncates toward zero. The original uses both deliberately. The angle normalisers ng, nb, nh are built on INT and land in [0, period), while wz, the degree within a zodiac sign, is built on FIX and keeps its sign. The port maps them to std::floor and std::trunc and its tests pin both behaviours.

Guards stay where he put them

The epsilon kk = 1e-10 appears in the original exactly where a division or an arctangent argument could hit zero. The port adds it in exactly those places and nowhere else, because the branch behaviour of the aspect logic depends on it.

Verification

The test suite currently holds 37 test cases with 273 assertions, all green, built with MSVC at warning level 4 with warnings as errors. The anchors are Jean Meeus's worked examples, the binary data files themselves and cross checks between independent engines, the Chapront theory against the integrated Pluto file among them. Golden fixtures recorded from the original program join the suite once the calculation chain produces full coordinate tables.

In memory of Robert Rettig, who built all of this first.
