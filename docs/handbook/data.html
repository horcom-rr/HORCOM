Purpose

The loaders that keep his files alive. Every format was specified byte level in the legacy analysis and verified against real files before a loader was written. Text arrives as Windows 1252 and is normalised to UTF-8 on read, numbers are right aligned like RSET STR$, text left aligned like LSET, and overlong text truncates exactly where his fields truncated it. The chart record

Day, month, astronomical year, hour in Universal Time, minutes with the seconds as fraction, longitude east positive, latitude north positive, then 25 bytes of name, 20 of place and 51 of remark. A remark starting with the calendar flag forces the Julian or the proleptic Gregorian calendar, the loader exposes it as the same Calendar enum the time module uses. There is no header and no index, sorting was always in memory.

Places

Eight bytes longitude, eight latitude, twenty name. The picker files carry the time zone difference in the last five name bytes, stored as the correction that leads from zone time to UT, so MEZ reads minus one. The preferred place file has two coordinate encodings in the wild, integer micro degrees from the write once writer and plain decimals from older files, the reader takes the original's branch on the missing decimal point including its kk epsilon.

Privacy rule

His real chart collections contain real people and never enter the repository. The loader tests run on synthetic records written on the fly, the byte layout itself was verified against non personal files, places and settings, during the analysis.

The settings stream

KONSTA7P.INT holds every calculation switch of the program. Its writer and reader split the fields across lines differently, GFA INPUT ignores line boundaries, so the loader tokenises the whole file first, quoted strings with commas inside included. The struct keeps his variable names as the schema, the mapping onto the pipeline settings follows kon_dhol with the sixteen to twelve divisor rule of the equal probability mode. Validated against his real settings file, which showed his own configuration ran with the topocentric parallax switched on.

The AAF exchange format

The tagged text format is the port archive format going forward. The parser takes the original quirks whole, the tilde as universal ignore marker, stars as empty fields, HTML stripped so saved web pages still parse, plain lines continuing a comment, the calendar suffix on the year and the rule that a Julian date outranks the clock fields. The writer reproduces the A93 and B93 lines of make_aaf including STR$(jd,13,5). Still open here, the seed conversion of the timezone and country tables.

Verification

test_data.cpp pins the 1252 round trip including the high row, the exact field offsets and alignments of an encoded chart record, file round trips with a BC year and the Julian flag, rejection of torn files, the place layout, the zone suffix readings for east and west, and both preferred place encodings.
